# 확정 개편 작업

목표: 일반 3종·번뜩임 6종 교체, 번뜩임 3종 추가. 총 74종. 번뜩임 10%, 개인별 독립 추첨 유지.

## 구현 목록

- tomorrow → 흑역사 세탁: 1~3 선택 순간 반대 눈을 저장. 현재 굴림 계속 가능. 다음 첫 굴림 보관. 턴당 1회, 게임당 2회.
- inspection → 보관함 털이: 다음 두 번째 일반 굴림에 보관 최대 2개 강제 투입. 강제 보관 제외. 게임당 2회.
- memory → 명장면 재방송: 과거 기록 결과 중 선택, 최대 앞 5개로 첫 굴림 재현. 게임당 2회.
- dropIt → 바나나 껍질: 다음 첫 굴림 최고 눈 하나를 1로 변경. 동률 무작위. 게임당 1회.
- receipt → 그거 굴리면 터진다: 다음 첫 굴림 하나에 폭탄. 다시 굴리면 시전자 +3, 안 굴리고 기록하면 대상 -4. 게임당 2회.
- broken → 그 버튼 이제 제 겁니다: 상대 사용형 골드 다음 턴 봉인, 시전자는 다음 자기 턴 종료까지 1회 대여. 게임당 1회.
- construction → 오늘 메뉴는 이겁니다: 다음 턴 빈칸 중 무작위 3개에만 기록. 빈칸 3개 이하 대상 불가. 게임당 1회.
- closed → 성적표 맞바꿔치기: 양쪽 이미 기록한 같은 하단 칸 점수 교환. 같은 점수 불가, 대상당 게임 중 한 번만 피해. 방어 적용, 기록 효과 재발동 금지. 게임당 1회.
- hostage → 악마의 택배: 다음 첫 굴림 후 10점 납부 또는 주사위 둘을 1로 변경하고 재굴림·눈 변경 봉인. 미리 보관된 주사위 제외. 게임당 1회.
- 신규 실버 번뜩임 방금 건 연습: 다음 첫 굴림 최고 눈 하나 자동 물리 재굴림. 횟수 보존. 게임당 1회.
- 신규 골드 번뜩임 택배 오배송: 내 눈 하나를 상대 직전 결과의 눈으로 변경하고, 상대 다음 첫 굴림은 내 원래 눈 하나 보관. 게임당 1회.
- 신규 프리즘 번뜩임 골드 대이동: 사용 가능한 골드 하나씩 다음 좌석으로 영구 이동. 방어 인원 제외, 2명 이상. 사용 횟수·사용 기록 유지. 게임당 1회.

## 완료 기준

서버 권한 검증, 선택 UI, 전체 사용자 동일 연출, 재접속 복구, 도감 및 설명, 리롤·방패·기권·평행세계 충돌 검사, 모든 카드 사용하는 자동 경기 2,000판, 브라우저 검사, Docker tar 갱신.

진행 상태는 실제 구현과 검증을 마친 항목만 별도로 기록한다. 이 문서 자체는 구현 완료를 뜻하지 않는다.

## 구현 완료 — 2026-11-02

위 12종의 서버 효과, 선택 UI, 설명·아이콘을 모두 구현했다. 전체 74종은 실버 26종 / 골드 27종 / 프리즘 21종이며, 번뜩임은 각각 5종 / 5종 / 6종이다.

- 과거 결과 목록에서 재방송할 기록을 고르고, 대여 능력에는 남은 횟수와 반납 시점을 표시한다. 메뉴 제한은 기록할 수 있는 3칸을 보여준다.
- 폭탄 주사위에는 테두리·폭탄 표시·설명을, 봉인 주사위에는 `1로 봉인` 표시와 보관 해제 금지를 적용한다. 공유 결과는 애니메이션 알림으로 보여주며 주사위판 영역을 줄이지 않는다. 동작 줄이기 설정도 지원한다.
- 자동 재투척은 서버 물리엔진으로 실행한다. 일반 굴림 횟수·다른 주사위·보관 상태를 보존하고 모든 클라이언트에 같은 결과와 위치를 전송한다.
- 봉인된 1은 상자 속 고양이로 되돌려도 유지한다. 첫 굴림 방해가 있으면 먼저 해결한 뒤 평행 던지기를 사용한다. 이 제한을 설명과 버튼에도 반영했다.
- 성적표 교환은 기록 효과를 재발동하지 않고 상단 기본 합계를 건드리지 않는다. 마지막 턴을 이미 마친 상대도 교환 대상이 될 수 있다. 피해 대상당 한 번, 방패로 차단 가능하다.
- 골드 이동은 남은 횟수·턴 사용 기록을 보존한다. 대여 능력은 이동 대상에서 제외하고, 방패 때문에 둘 미만이 남으면 교환 없이 종료한다. 중복 골드는 의도적으로 허용한다.

## 검증 결과

- 전체 테스트 **131개 통과**: 공유·서버 97개 + 클라이언트 34개. 이후 마지막 문구·표시 정리와 함께 공유 규칙/재굴림 53개, 추가 경계 검사 51개도 통과했다.
- 포맷 검사, 클라이언트/서버 타입 검사, 프로덕션 빌드 통과.
- 자동 경기 2회, 총 **4,000판** 완주. 최종 코드 검사(seed 20261106)는 **2,000판 / 71,988턴 / 성공 행동 528,437회 / 선택지 새로고침 4,869회**, 미사용 사용형 능력 0종. 의도적으로 불법 조합도 시도해 거부·상태 보존을 검사했다.
- 실제 난수원 `crypto.randomInt`로 4좌석 × 4선택 라운드 × 10,000표본 = **160,000개 선택지 세트** 검사. 좌석·라운드별 번뜩임 관측률 **9.45~10.30%**. 선택지는 독립 추첨이므로 우연히 겹칠 수 있다.
- 실제 서버 물리 재투척, A/B 선택, 4~10개 주사위, 벽·컵·보관 주사위 분리, 재접속 검증 통과.
- Chrome 4개 클라이언트, 390/780/1366/1440px 화면, 도감 맨 위·중간·맨 아래, 모든 개편 입력, 폭탄·봉인 표시 검증. 브라우저 오류 0건. 4인 플레이어 영역 스크롤 없음, 주사위·버튼이 화면 안에 들어옴.
- Docker tar를 실제로 다시 불러와 컨테이너 실행, HTTP 정상 응답, 두 사용자 방 생성→증강 선택→물리 투척과 숫자·위치 일치 확인.

위 수치는 커밋 전 실행 결과다. 생성된 로그·JSON·스크린샷은 저장소 정리 때 삭제하고 Git에서 제외했다. `npm test`, `scripts/stress-augments.mjs`, `scripts/audit-offers.mjs`, `scripts/check-augments.mjs`로 재검증하면 `artifacts/`에 결과를 다시 생성할 수 있다.

## 밸런스 해석과 제한

실버는 한두 주사위의 일시적 장난과 제한된 사용 횟수, 골드는 보관·기록 선택·능력 사용을 흔드는 효과, 프리즘은 점수표·능력 소유권·턴 전체 봉인을 바꾸는 효과로 차이를 뒀다. 방패, 예약 방해 1개 제한, 사용 횟수, 대상 조건을 유지했다. 점수 교환은 직접 피해 10점 제한의 예외다.

5/6/7개 주사위별 1,000개 상황도 분석했다. `node scripts/choice-balance.mjs 1000`으로 보고서를 재생성할 수 있다. 단순 봇의 반응을 비교한 참고치이며 사람의 승률이나 최적 전략을 뜻하지 않는다. 특히 1 두 개 봉인은 원스·풀하우스에 역이용될 수 있고, 자동 재굴림이 상대에게 더 좋은 눈을 줄 수도 있다. 방해가 항상 이득을 보장하지 않는 설계다. 기존 비교 봇이 처리하지 못하는 개편 능력은 그 보고서에서 제외하고 별도 상황 분석·실제 엔진 스트레스 검사를 사용한다.

자동 경기는 합성 균등 주사위를 사용하므로 물리엔진의 확률 공정성이나 실전 능력별 승률을 증명하지 않는다. 실제 기기 간 LAN 플레이·장기간 플레이 밸런스는 별도 관찰 대상이다.
