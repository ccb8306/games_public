## 2. 게임의 핵심은 세 가지 시스템

### A. 증강 시너지

단순히 좋은 증강을 뽑는 게 아니라, 기존에 선택한 증강과 연계해야 강해지도록 만드는 거지.

예를 들어 `1이 나오면 이득`인 증강을 골랐으면, 다음에는 6을 1로 바꾸는 증강이 매력적으로 보이도록.

### B. 판 전체에 적용되는 '난장판 사건'

3·6·9·12라운드마다 모든 플레이어에게 공통으로 적용되는 규칙을 하나 뽑는 거야.

### C. 직접 방해와 대응 수단

상대 주사위를 봉인하거나, 증강을 교환하거나, 점수를 강탈하는 것까지 가능하게 하자.

대신 견제를 전혀 방어할 수 없으면 짜증만 나니까 저주 해제나 보호 효과도 넣어야 해.

# 4. 공용 이벤트: 난장판 시스템

여기서부터 증강 윷놀이의 맛을 더할 거야.

증강은 개인마다 다르지만, 난장판 이벤트는 모든 플레이어의 행동에 영향을 줘.

3·6·9·12라운드 시작 전에 하나씩 뽑고, 해당 라운드가 끝나면 사라지는 방식이야.

## 난장판 이벤트 8종

01\. 거꾸로 세계

모든 플레이어는 최종 굴림 후 주사위 하나를 반대 눈으로 뒤집을 수 있다. 사용하지 않아도 됨.

02\. 속전속결

모든 플레이어의 최대 굴림 횟수 -1. 대신 기본 족보 점수가 1점 이상이면 보너스 +10점.

03\. 주사위 과잉 공급

이번 라운드만 모든 플레이어가 주사위를 하나 더 굴리고, 점수 기록 시 5개를 선택한다.

04\. 정부 지원금

이번 턴 기본 점수가 0점이면 별도 보너스 +12점, 1\~15점이면 +6점을 얻는다.

05\. 폭탄 돌리기

첫 굴림 전 폭탄을 선택할 수 있다. 선택 시 최종 주사위에 6이 3개 이상이면 +20점, 아니면 -8점.

06\. 혼돈의 선택

모든 플레이어는 최종 주사위 하나를 무료로 다시 굴릴 수 있다. 단, 새 결과를 반드시 사용해야 한다.

07\. 빚내서 굴려

모든 플레이어가 -8점의 별도 페널티를 받는 대신 굴림 횟수 +1을 선택할 수 있다.

08\. 숫자 교환소

두 번째 굴림 이후 원하는 주사위 하나를 반드시 다시 굴리는 대신 보너스 +8점을 받을 수 있다. 새 결과 복구 불가.

이 이벤트들은 기본적으로 플레이어 모두에게 공평하게 제공돼. 하지만 이미 가진 증강에 따라 그 이벤트를 활용하는 효율이 달라지는 거지.

예를 들어 `6의 신봉자`를 가지고 있는 사람에게 '폭탄 돌리기'가 나오면? 갑자기 완전히 다른 게임이 시작되는 거야.

## 점수 계산 우선순위

| 순서 | 처리 내용              |
| -- | ------------------ |
| 1  | 최종 주사위 및 와일드 숫자 결정 |

권장 추가 규칙은 다음과 같아.

- 상단 63점 보너스: 기존 야추에서 인정하는 상단 기본 점수만 계산. 별도 증강 보너스는 제외.
- 같은 능력의 중복 획득 불가: 도플갱어처럼 의도적으로 능력을 복제하는 경우는 예외.
- 무료 굴림과 추가 굴림 구분: 굴림 횟수를 증가시키는 효과와 특정 주사위만 다시 굴리는 효과를 별개로 취급.
- 한 플레이어에게 동시에 적용할 수 있는 예약형 방해 효과는 최대 1개: 중복 저주로 턴 자체가 무너지는 것을 방지.
- 한 턴에 상대가 직접 빼앗거나 감소시킬 수 있는 점수는 최대 10점: 간접적인 점수 경쟁은 이 제한에 포함하지 않음.

# 8. 밸런스는 어떻게 잡을까?

증강은 전부 강력할 필요가 없어. 오히려 모든 능력이 똑같이 강하면 선택의 재미가 없거든.

하지만 의도적으로 쓰레기 증강을 만드는 건 추천하지 않아.

각 능력이 특정 상황이나 특정 조합에서는 선택할 이유가 있어야 해.

### 목표 밸런스

| 등급  | 증강 하나가 게임 전체에서 만들어내는 추가 점수 가치 목표 |
| --- | -------------------------------- |
| 실버  | 약 15\~30점                        |
| 골드  | 약 20\~45점                        |
| 프리즘 | 약 25\~55점                        |

이 수치는 확정된 기대값이 아니라 초기 밸런싱 목표치야. 주사위 확률 시뮬레이션과 실제 플레이로 조정해야 해.

주사위 조작 효과는 단순히 몇 점을 추가했는지로 평가하면 안 돼. 조작 덕분에 야추가 가능해지거나 0점을 피한 가치까지 계산해야 하니까.

### 선택지 생성 알고리즘

증강 3개를 무작위로만 주기보다는 이렇게 섞는 걸 추천해.

1번 선택지

내 기존 증강과 시너지가 있는 능력

2번 선택지

완전 무작위 능력

3번 선택지

도박·견제·변칙 계열 능력

시너지 후보가 없거나 해당 등급의 선택지가 부족하면 무작위 카드로 채우면 돼. 특정 조합을 무조건 완성시켜주는 방식은 아니고, 완성 가능성을 높여주는 정도가 적당해.

이렇게 하면 `실버에서 뭘 골랐느냐`가 중반 증강 선택에도 자연스럽게 영향을 주게 돼.

# 9. 실제 구현 우선순위

48종을 한 번에 만드는 건 추천하지 않아. 네가 이미 만든 야추 게임에 얹는 거니까, 기존 로직을 최대한 재사용하는 구조로 가자.

1차: 증강 엔진 + 핵심 24종

실버 8종, 골드 10종, 프리즘 6종.

주사위 조작, 족보 변경, 점수 보너스, 배율 및 효과 발동 시점까지 구현. 우선 상대 견제형 없이 테스트.

2차: 상대 견제 + 난장판 이벤트

예약형 효과, 대상 선택, 효과 무효화, 공용 이벤트 적용, 효과 충돌 처리 구현.

3차: 특수 프리즘 + 전체 48종

평행세계, 추가 주사위, 점수표 재작성, 증강 교환·복제 등의 복잡한 기능과 카드별 애니메이션.

4차: 밸런스 시뮬레이션

수만\~수십만 판의 자동 플레이로 증강 선택률, 승률 기여도, 평균 득점, 특정 시너지의 점수 폭발 가능성 분석.

구현 측면에서는 `AugmentDefinition`과 `AugmentInstance`를 구분하는 게 좋아.

전자는 증강의 기본 정의이고, 후자는 실제 플레이어가 보유한 증강의 남은 사용 횟수·지속 시간·상태를 관리해.

또한 모든 점수 보정은 주사위 값 직접 변경 → 족보 판정 변경 → 족보 점수 변경 → 별도 보너스 → 상대 효과처럼 단계별로 처리해야 디버깅이 쉬워질 거야.

# 10. 이 기획에서 한 가지 더 욕심내고 싶은 부분

나는 증강을 얻는 것만큼 증강을 포기하는 선택도 재미있을 것 같아.

가령 7라운드에서 골드 증강을 받는 대신, 기존 실버 증강 하나를 희생해서 더 강력한 특수 골드 증강을 얻는 방식이지.

이걸 '증강 진화'라고 부를 수 있겠어.

손끝 보정

주사위 ±1

현실 조작

매 턴 주사위 ±2

기존 실버를 제거하고 진화형 골드를 획득. 일반 골드 선택을 대체하므로, 증강 슬롯 수는 그대로 유지.

이런 진화형을 모든 증강에 줄 필요는 없어. 인기 있는 빌드 몇 개만 별도 진화 트리로 만들면 충분해.

오히려 나중에 증강 수가 100개를 넘었을 때 콘텐츠를 확장할 수 있는 좋은 수단이 될 거야.

## 최종적으로 내가 지향하는 게임

처음에는 평범하게 주사위를 굴리다가, 중반에는 내가 만든 빌드로 확률을 바꾸고, 후반에는 상대와 서로의 규칙을 뒤엎는 게임.

그런데 마지막에 이겨도 단순히 사기 능력을 뽑아서 이겼다는 느낌보다는, 내가 증강을 잘 조합하고 적절한 순간에 사용해서 이겼다는 느낌이 남아야 해.

그리고 실제로 만들 때는 한 가지 더 신경 쓰자.

개판은 화려하게, 조작은 간단하게.

증강마다 버튼이 다섯 개씩 생기고 매 굴림마다 팝업이 뜨면 재미보다 피로도가 높아져. 상시 능력은 자동 처리하고, 사용형만 필요한 순간에 버튼을 표시하는 방식이 좋겠어.

지금 이 기획은 기본 13라운드 야추를 가정했어. 실제 게임의 턴 진행 방식과 점수표에 맞게 조정한다면, 꽤 완성도 있는 독립 게임 모드가 될 수 있을 것 같아.

특히 나는 '상자 속 고양이', '왕의 압수수색', '지워진 0' 같은 능력이 이 게임의 간판 증강이 될 가능성이 크다고 봐. 기존 야추에서는 절대로 일어날 수 없는 일을 만들어 주니까.
